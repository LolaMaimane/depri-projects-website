# Depri Projects CC — Website

Static website for **Depri Projects CC** (Reg. 2002/013092/23), supplier of aggregates, granite, gravel, marble stone, river sand and building sand, plus mining, transport and agricultural services.

- `index.html` — home page
- `about.html`, `products.html`, `services.html`, `operations.html`, `contact.html` — inner pages (header/footer are repeated in each file; edit all six when changing the menu)
- `404.html` — not-found page; `sitemap.xml`, `robots.txt` for search engines
- `capability-statement.html` — web capability statement (printable A4); PDF in `assets/docs/`
- `assets/css`, `assets/js`, `assets/img`

## Editing
Plain HTML/CSS/JS, no build step. Open `index.html` in a browser to preview.

## Contact form
The form posts to [FormSubmit](https://formsubmit.co) and is delivered to `info@fhdepriprojects.com`. The **first** submission sends an activation email to that inbox; click the link once to start receiving enquiries. Change the address in the `<form action>` in `contact.html` once the company domain email is set up.
